# Roteiro de avaliação técnica

## 1. Entendimento da operação

O primeiro passo é definir o cenário: tipo de empreendimento ou operação, quantidade de unidades, pontos de atendimento, dispositivos existentes, integrações necessárias e expectativas de disponibilidade.

## 2. Demonstração orientada ao fluxo

A demonstração é conduzida por fluxos reais de trabalho. Para o PBX, por exemplo, pode incluir uma chamada e suas regras de encaminhamento. Para o VMS, a conversa pode partir da gestão de dispositivos e da visualização. Para o Core, o foco é a forma como os recursos compartilhados são incorporados aos produtos.

## 3. Validação de aderência

Depois da demonstração, são registrados os requisitos confirmados, as integrações necessárias e os pontos que pedem prova de conceito. Esse registro define um próximo passo objetivo.

## 4. Análise aprofundada

Quando houver necessidade de examinar arquitetura, código ou detalhes de infraestrutura, o acesso é tratado de forma restrita e mediante condições previamente acordadas. A apresentação pública não substitui esse processo.

## Informações que não são solicitadas nesta etapa

Não é necessário compartilhar senhas, chaves, bases de dados, diagramas de rede detalhados ou informações de clientes para uma primeira avaliação.
